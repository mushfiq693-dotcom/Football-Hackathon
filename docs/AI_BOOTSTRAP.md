# Football Auction Platform

## Project

Football Auction Platform for the CSE Department Tournament.

The platform allows admins to organize player auctions and captains to bid on players in real time.

---

## Tech Stack

Frontend

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

Backend

- Supabase
- PostgreSQL

Authentication

- Supabase Auth

Realtime

- Supabase Realtime

State

- Zustand

Validation

- React Hook Form
- Zod
